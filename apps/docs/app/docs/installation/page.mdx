# Installation

This page explains how to get Astro into a runnable state. It separates the setup model from command lists so readers understand what each step is preparing.
## Setup Model
Installation has two jobs: install the package dependencies and verify the command or package entrypoint that exercises the main workflow.
## What Gets Configured
- Dependencies provide the framework, CLI, adapters, and runtime libraries used by the project.
- Scripts provide repeatable entrypoints for local development, production builds, tests, and release tasks.
## Create the Bot Application
- Create the bot or application in the messaging platform before starting the local process.
- Enable the message access or intent settings required by that platform so the bot can see user questions.
- Invite the bot into the server, workspace, channel, or chat where you want to test it.
## Successful Setup Looks Like
- Dependencies install with the package manager already used by the project.
- The bot logs in, receives a test message, and replies in the same conversation without undocumented manual steps.
## Install Dependencies
Run `pnpm install` from the project root.

## Useful Commands
- `build` runs `turbo run build --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `dev` runs `turbo run dev --concurrency=40 --parallel --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and starts the local development workflow.
- `test` runs `turbo run test --concurrency=1 --filter=astro --filter=create-astro --filter="@astrojs/*"` and runs verification for expected behavior.
