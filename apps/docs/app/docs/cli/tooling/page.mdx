# CLI and Development Tools

The CLI page explains terminal-driven workflows, command entrypoints, development tooling, and the flags developers use while working locally.
## Purpose and Scope
This area owns terminal-first workflows such as local development, setup helpers, watch mode, and project automation. It is where maintainers and contributors interact with the repo without opening the browser.

## Useful Commands
- `build` runs `turbo run build --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `dev` runs `turbo run dev --concurrency=40 --parallel --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and starts the local development workflow.
- `test` runs `turbo run test --concurrency=1 --filter=astro --filter=create-astro --filter="@astrojs/*"` and runs verification for expected behavior.
- `lint` runs `eslint . --report-unused-disable-directives` and checks or fixes code style before changes are shipped.
- `build:ci` runs `turbo run build:ci --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `format` runs `pnpm run format:code && pnpm run format:imports` and checks or fixes code style before changes are shipped.
- `format:ci` runs `pnpm run format:code:ci && pnpm run format:imports:ci` and checks or fixes code style before changes are shipped.
- `format:imports` runs `biome check --apply .` and checks or fixes code style before changes are shipped.
