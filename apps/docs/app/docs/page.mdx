# Introduction

Astro is the all-in-one web framework designed for speed. It ships zero JavaScript by default, renders your pages to static HTML at build time, and selectively hydrates only the interactive components you actually need. The result is sites that are fast by architecture, not by discipline.

Astro is built around a component model that works with the UI framework you already know. React, Preact, Svelte, Vue, Lit, Solid, and Alpine are all first-class citizens — you can even mix them on the same page. If you prefer no framework at all, Astro's own `.astro` template syntax gives you HTML-first components with optional TypeScript frontmatter.

The project is a monorepo managed with `pnpm` and Turborepo. The core `astro` package lives in `packages/astro` and ships the CLI, dev server, build pipeline, content collections runtime, and image optimization services as a single cohesive tool.
