# Self-Hosting

These pages cover self-hosting for Astro.

## When to Use This Section
Self-hosting pages clarify how Astro runs in an environment you own, what belongs to the host application, what the package provides, and what must be verified before production use.

## Available Pages
- [Astro Setup](/docs/self-hosting/astro) - Astro setup shows how to mount the product inside an Astro host application.

## Reading Order
- Start with the page closest to the workflow you are trying to complete.
- Use setup and configuration pages before running commands in a new environment.
- Use reference pages when you already know the concept and need exact commands, imports, or options.
