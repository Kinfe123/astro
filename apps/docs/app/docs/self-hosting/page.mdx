# Self-Hosting

Use this section to find the self-hosting pages for Astro.

## When to Use This Section
Use this section when Astro needs to run in an environment you own. These pages clarify what belongs to the host application, what the package provides, and what must be verified before production use.

## Available Pages
- [Astro Setup](/docs/self-hosting/astro) - Astro setup shows how to mount the product inside a Astro host application.

## Reading Order
- Start with the page closest to the workflow you are trying to complete.
- Use setup and configuration pages before running commands in a new environment.
- Use reference pages when you already know the concept and need exact commands, imports, or options.
