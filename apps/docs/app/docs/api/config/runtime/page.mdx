# Runtime Config

Runtime config defines the options developers pass when wiring the package into an application.
## Contract
This API reference page explains the configuration shape developers pass into the package, which options are part of the public contract, and which feature pages depend on those settings.
## Key Ideas
- configuration type
- runtime options
- validation
- public contract
## Configuration Entry Points
- `astro/config` - Configuration contract or helper export.
- `astro/config.d.ts` - Configuration contract or helper export.
- `astro/config.mjs` - Configuration contract or helper export.

## How To Use This Contract
- Start with the exported configuration helper or type rather than copying internal schema files.
- Keep runtime options tied to the feature, adapter, or deployment behavior they control.
- Treat example configs as usage examples; the primary source export is the contract.
