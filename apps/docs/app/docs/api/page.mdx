# API Reference

These pages cover API reference for Astro.

## When to Use This Section
The API reference collects the concrete developer surface of Astro: terminal commands, import paths, route handlers, adapters, configuration helpers, and type contracts. Start with the page that matches what you are trying to call or run, then move to setup and configuration pages when you need the surrounding runtime context.

## Available Pages
- [CLI](/docs/api/cli) - Commands and flags for running repository workflows from the terminal.
- [Configuration API](/docs/api/config) - Configuration types, helpers, and contracts used by application developers.

## Reading Order
- Choose CLI pages when you need commands, flags, or terminal workflows.
- Choose export or adapter pages when you need import paths, package entrypoints, or framework integration contracts.
- Use configuration pages alongside API pages when an API depends on environment values, secrets, or runtime options.
