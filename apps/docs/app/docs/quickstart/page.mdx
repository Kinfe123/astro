# Quickstart

This guide takes you from zero to a running Astro site. By the end you'll have a local dev server serving a page you wrote.

## Step 1 — Create a project

Run the scaffolding wizard and follow the prompts:

```bash
npm create astro@latest
```

Choose a project name, pick a starter template, and let the wizard install dependencies. Then move into your new directory:

```bash
cd my-astro-site
```

## Step 2 — Start the dev server

```bash
npm run dev
```

Astro starts the development server and prints a URL like `http://localhost:4321`. Open it in your browser — you'll see the starter page rendered and ready to edit.

## Step 3 — Edit a page

Open `src/pages/index.astro`. The `.astro` format is a superset of HTML. A minimal page looks like this:

```astro
---
// Component Script (optional)
const greeting = "Hello, Astro!";
---

<html lang="en">
  <head>
    <title>My Site</title>
  </head>
  <body>
    <h1>{greeting}</h1>
  </body>
</html>
```

Save the file and the browser refreshes automatically.

## Step 4 — Build for production

When you're ready to generate static output:

```bash
npm run build
```

Astro writes the built site to `dist/`. You can preview it locally with:

```bash
npm run preview
```

## Step 5 — Add an integration (optional)

Use `astro add` to install a UI framework integration. For example, to add React:

```bash
npx astro add react
```

The command installs the required packages and updates your `astro.config.mjs` automatically. Pass `--yes` to skip confirmation prompts.
