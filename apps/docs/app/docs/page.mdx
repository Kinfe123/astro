# Astro

Astro is a modern site builder with web best practices, performance, and DX front-of-mind.
## Product Story
Astro is documented as a messaging product: how the bot connects to its platform, how people ask questions, how the project gathers context, and how a useful answer gets sent back. The docs should orient operators and contributors before they need to inspect source files.

## Core Capabilities
- Documentation Lookup: This workflow turns a user question into usable documentation context. It sends the question to the configured documentation source, parses the returned sections, keeps useful metadata such as titles and source links, and hands the best context to the response step. Key concepts: docs retrieval, query text, source links, code examples.
- Developer Tools: This section explains the utilities that help developers inspect, configure, or generate parts of the product. These tools are not just UI screens; they are shortcuts for common setup, debugging, schema, email, or integration work. Key concepts: developer tools, generators, inspectors, visual editors.
- Messaging Bot: This page explains the bot runtime from a user and operator point of view: how messages enter the app, which messages the bot responds to, what feedback it gives while working, and which credentials must be present before it can connect to the platform. Key concepts: bot runtime, message events, mentions, commands.
- Event Tracking: This capability turns runtime activity into a timeline that administrators can inspect. It is especially useful for auth products because sign-ins, session creation, account updates, and organization events often need auditability and context. Key concepts: events, audit trail, activity feed, last seen.

## Common Commands
- `build` runs `turbo run build --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `dev` runs `turbo run dev --concurrency=40 --parallel --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and starts the local development workflow.
- `test` runs `turbo run test --concurrency=1 --filter=astro --filter=create-astro --filter="@astrojs/*"` and runs verification for expected behavior.
