# Render

Render explains the responsibility boundary around `core/render`.
## What This Area Covers
Render explains the `core/render` behavior that readers can rely on before they inspect supporting files.
## What It Actually Does
- `validatePrerenderEndpointCollision(route: RouteData, mod: ComponentInstance, params: Params)` - If we have an endpoint at `src/pages/api/[slug].ts` that's prerendered, and the `slug` is `undefined`, throw an error as we can't generate the `/api` file and `/api` directory at the same time. Using something like `[slug].json.ts` instead will work.
