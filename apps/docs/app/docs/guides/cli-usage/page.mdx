# CLI Usage

CLI usage explains the commands and flags developers use to initialize, run, and debug the product.
## Goal
CLI usage explains the command-line mental model: which commands exist, when to use each command, which flags affect runtime behavior, and how the CLI discovers project configuration.
## Key Ideas
- commands
- flags
- config discovery
- local development
- standalone server
## Before You Start
- Install dependencies with `pnpm install`.
- Confirm the main workflow with `pnpm dev`.
- Review required configuration before running commands that create or mutate data.
## Run The Workflow
1. Install or run the CLI from the host project root.
2. Choose the command that matches the task, such as starting the studio or initializing config.
3. Pass flags for port, host, config path, watch mode, or other runtime behavior when defaults do not match the app.
## Useful Commands
- `dev` runs `turbo run dev --concurrency=40 --parallel --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and starts the local development workflow.
- `build` runs `turbo run build --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `test` runs `turbo run test --concurrency=1 --filter=astro --filter=create-astro --filter="@astrojs/*"` and runs verification for expected behavior.
- `release` runs `pnpm run build && changeset publish` and prepares or publishes package releases.
- `build:ci` runs `turbo run build:ci --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `build:examples` runs `turbo run build --filter="@example/*"` and creates the production build or compiled package artifacts.
