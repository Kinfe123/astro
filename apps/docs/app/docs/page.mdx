# Introduction

Astro is a modern web framework built for speed and developer experience. It lets you author components in your preferred UI library — React, Preact, Svelte, Lit, Alpine, or plain HTML — and ships zero JavaScript to the browser by default. The result is static HTML that is fast to serve and easy to cache, with islands of interactivity only where you actually need them.

The framework covers the full project lifecycle: a scaffolding CLI to create new projects, a development server with hot module replacement, a production build pipeline powered by Vite, image optimization services, a typed content collections system, and an adapter model for deploying to Node.js, edge runtimes, or static hosts.
