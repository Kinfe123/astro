# Introduction

Astro is the all-in-one web framework designed for speed. It lets you build content-rich sites using your favorite UI framework — React, Preact, Svelte, Lit, Alpine, or plain HTML — while shipping zero JavaScript to the browser by default. Every page is rendered to HTML at build time or on the server, so your users get fast, accessible pages without a heavy client runtime.

The framework is built around a few strong opinions: ship less JavaScript, render HTML first, and give developers a clean authoring experience with `.astro` components and a file-based routing system. When you do need interactivity, Astro's island architecture lets you hydrate individual components selectively rather than the entire page.

This repository is a pnpm monorepo. The core `astro` package lives in `packages/astro` alongside official integrations under `packages/integrations/` and a collection of starter examples in `examples/`. The `create-astro` scaffolding tool is a separate package in the same workspace.

If you're new, head to [Quickstart](/docs/quickstart) to scaffold and run your first project in under two minutes. If you're installing into an existing project, see [Installation](/docs/installation). For configuration options and deployment, the [Configuration](/docs/configuration) section has you covered.
