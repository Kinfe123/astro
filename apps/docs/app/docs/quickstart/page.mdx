# Quickstart

This is the shortest path from clone to a useful first run of Astro. The goal is not to understand every file yet; the goal is to install dependencies and run the command or package entrypoint that proves the project is alive.
## What You Will Accomplish
- Prepare the bot process with the detected package manager.
- Add the platform token and model/provider credentials needed for runtime behavior.
- Ask one test question so you can confirm the bot is usable before exploring advanced docs.
## Before You Start
This project uses `pnpm` as its package manager.
No README or example environment file defines required variables, so do not treat source-only environment reads as the first-run checklist.
## Recommended First Run
1. Install dependencies with `pnpm install`.
2. Run `pnpm dev` to exercise the main workflow.
3. Send a small test question through the messaging platform and verify the bot replies.
## Expected Result
The bot should acknowledge the question and return a useful answer in the same channel. If it stays silent, check the bot token, platform permissions or intents, and any AI/provider keys listed on the environment page.
## Useful Commands
These commands are useful after the first run because they are the repeatable workflows available in the project.
- `build` runs `turbo run build --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `dev` runs `turbo run dev --concurrency=40 --parallel --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and starts the local development workflow.
- `test` runs `turbo run test --concurrency=1 --filter=astro --filter=create-astro --filter="@astrojs/*"` and runs verification for expected behavior.
