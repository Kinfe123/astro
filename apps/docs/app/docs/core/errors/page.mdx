# Errors

Errors explains the responsibility boundary around `core/errors`.
## What This Area Covers
Errors explains the `core/errors` behavior that readers can rely on before they inspect supporting files.
## What It Actually Does
- `collectErrorMetadata(e: any, rootFolder?: URL | undefined): ErrorWithMetadata` - Takes any error-like object and returns a standardized Error + metadata object. Useful for consistent reporting regardless of where the error surfaced from.
- `getKebabErrorName(errorName: string): string` - The docs has kebab-case urls for errors, so we need to convert the error name Parameters: errorName.
- `renderErrorMarkdown(markdown: string, target: 'html' | 'cli')` - Render a subset of Markdown to HTML or a CLI output
- `getViteErrorPayload(err: ErrorWithMetadata): Promise<AstroErrorPayload>` - Generate a payload for Vite's error overlay

## Behavior Notes
- Recognizes package markers such as `type`, `title`.
- Normalizes inputs to values such as `type` -> `error`, `title` -> `Unknown compiler error.`.
