# Quickstart

Use this page as the shortest path from clone to a useful first run of Astro. The goal is not to understand every file yet; the goal is to install dependencies, provide required configuration, and run the command that proves the project is alive.
## What You Will Accomplish
- Prepare the project with the detected package manager.
- Add the minimum environment configuration needed for runtime behavior.
- Run the primary workflow so you can confirm the project is usable before exploring advanced docs.
## Before You Start
This project uses `pnpm` as its package manager.
Environment-backed behavior is present, so configuration is part of the first-run path.
## Recommended First Run
1. Install dependencies with `pnpm install`.
2. Copy `env.example` to `.env` and set the required values.
3. Run `pnpm dev` to exercise the main workflow.
## Useful Commands
These commands are useful after the first run because they are the repeatable workflows available in the project.
- `build` runs `turbo run build --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and creates the production build or compiled package artifacts.
- `dev` runs `turbo run dev --concurrency=40 --parallel --filter=astro --filter=create-astro --filter="@astrojs/*" --filter="@benchmark/*"` and starts the local development workflow.
- `test` runs `turbo run test --concurrency=1 --filter=astro --filter=create-astro --filter="@astrojs/*"` and runs verification for expected behavior.
